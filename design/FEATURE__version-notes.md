# FEATURE__version-notes

版本号回答「第几次保存」，不回答「为什么改」。本功能给每个版本附加一条可选备注，让 `bakon log` 能直接说明「把端口改成 8843」这类意图。备注不参与内容寻址，也不改变版本编号、时间、来源或保留策略。

## 1. 使用方式

| 场景 | 命令 |
|---|---|
| 编辑前就知道要改什么 | `bakon edit ./nginx.conf -m "把监听端口改成 8843"` |
| 回退并说明原因 | `bakon revert ./nginx.conf 3 -m "回退到端口修改前的配置"` |
| 事后补记或修改备注 | `bakon note ./nginx.conf 3 "把监听端口改成 8843"` |
| 查看单条备注 | `bakon note ./nginx.conf 3` |
| 删除备注 | `bakon note ./nginx.conf 3 --clear` |
| 在历史中查看 | `bakon log ./nginx.conf` |

规则：

- `edit -m`、`revert -m` 的备注只属于这次命令实际创建的新版本。
- `edit` 没有内容变化时不创建版本，备注也不写入；命令提示 `no changes ...; note not recorded` 并退出 0。
- `revert` 的目标已经等于当前内容时不创建版本，备注同样不写入，并提示 `note not recorded`。
- 首次纳管的基线版本 0 不自动带备注；需要时用 `bakon note <file> 0 "..."` 显式添加。
- `bakon note` 只改注解，不创建版本、不触碰目标文件；可以修改或删除已有备注。
- 备注在钩子中通过 `BAKON_NOTE` 提供给命令；没有备注时为空字符串。

## 2. 数据格式

`VersionRecord` 增加可选字段 `note`：

```json
{
  "ver": 3,
  "blob": "…",
  "size": 428,
  "codec": "deflate",
  "time": "2026-11-10T12:03:11Z",
  "source": "edit",
  "note": "把监听端口改成 8843"
}
```

`note` 的约束在 `Note` newtype 中一次定义，读写两侧共用：

- 去掉首尾空白后必须非空。
- 最多 500 个字符（Unicode scalar value，不是字节）。
- 不允许任何控制字符，包括换行、回车和制表符；因此备注是单行。
- JSON 中缺省表示没有备注；写出时 `None` 不序列化该字段。

备注是**注解**，不是版本事实：版本号、内容哈希、大小、时间、来源仍由清单中的对应字段唯一决定；`note` 可以被后续的 `bakon note` 修改，而其他字段不会因此改变。

## 3. schema 与兼容

清单 schema 分为两档：

| schema | 含义 |
|---|---|
| 1 | 不含备注字段的清单 |
| 2 | 允许 `versions[].note` 的清单 |

- 读取器接受 schema 1 和 2。
- 写入器在没有备注时保持 schema 1；第一次写入备注时升级为 2；当所有备注都被删除或带备注的版本被裁剪后，降回 1。
- 标记文件、`index.json` 与 `.pending` 的 schema 仍为 1，与本功能无关。
- 旧版本程序（1.0.x）无法读取 schema 2 清单：`note` 是未知字段，会按清单损坏退出 6。反向兼容（新程序读旧数据）成立；前向兼容从未承诺。没有备注的清单仍保持 schema 1，因此旧程序可以继续读取大多数历史。

`log --format json` 增加 `note` 键：有备注为字符串，没有为 `null`。`--format plain` 在原有四个字段之后追加第五个字段 `note`，没有备注时为空字符串。`--format human` 增加 `note` 列。

## 4. 并发与持久性

`bakon note` 是清单写操作，使用与其他写命令相同的排他锁和原子替换：

1. 取排他锁。
2. 读清单，按版本号定位；版本不存在返回 3，已裁剪返回 3。
3. 修改或删除该版本的 `note`，必要时调整清单 schema。
4. 原子替换清单。

不写对象、不写 `.pending`、不触碰目标文件。清单替换成功即提交；父目录 `fsync` 失败返回 9，语义与其他清单写一致。备注写入不会与并发提交交错：排他锁内的读—改—写看到的是最新清单。

## 5. 验收

- `edit -m`、`revert -m` 生成的版本带有备注；无变化时不产生版本或备注。
- `bakon note` 可以显示、设置、替换和删除备注，且不改变版本数量和内容。
- `log` 的 human/plain/json 三种输出都能看到备注；JSON 无备注时为 `null`。
- 空备注、控制字符和超过 500 字符的备注退出 2，不写清单。
- 备注只影响 schema 1/2 的切换；无备注的清单仍是 schema 1。
- 钩子收到 `BAKON_NOTE`。
- 备注在 `prune`、`mv`、`verify --fix` 后保留；带备注的版本被裁剪后备注随版本消失。

## 6. 非目标

- 不支持多行备注、备注搜索或按备注过滤历史。
- 不支持给已裁剪的版本补备注。
- 不把备注纳入内容哈希、diff 或保留策略。
- 不自动从 diff 或编辑器内容推断备注。
